# Hi, I'm Agenor 👋

**Senior Fullstack Web Engineer** — building production software since 2002.

I work end to end in TypeScript — **Bun** and **Node.js** on the server, **Vue 3**
and **React** on the front — and I'm just as comfortable in the layer underneath:
**Go** services, **Kubernetes**, and the databases and pipelines that keep it all
running.

Right now I architect and operate a distributed device-management platform
running across **20,000+ endpoints**: a Go API with a WebSocket gateway and a
DAG-based task engine, a Vue 3 + TypeScript admin panel, a headless Windows
agent, and the full Kubernetes deployment.

### 🚀 What I've been building

**Distributed fleet management platform** — 20,000+ endpoints
Go API · WebSocket gateway · DAG task engine · Vue 3 SPA · Kubernetes
Remote configuration, monitoring and command orchestration across a live fleet
of 1,100+ connected nodes. Sole architect.

**Sharded mesh VPN, live-migrated**
Headscale · Go · Kubernetes
Split a single control plane that had hit its memory ceiling into 6 sharded
servers, then migrated 300+ production nodes between shards — zero downtime.

**Topology-driven network policy engine**
Go · graph modeling
Derives network ACLs automatically from network topology using a
connected-component model, replacing hand-written configuration entirely.

**Cross-platform desktop agent**
Go · Wails v2 · Windows SCM API
Headless Windows service plus system-tray GUI, with an S3-backed auto-update
pipeline using jittered rollout and per-machine, per-network and global gating.
